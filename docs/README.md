## 読み方の約束

本文は 3 種類の事実を区別して書いてある。

- **実測**: 端末またはホストでコマンドを実行して得た出力。数値は加工していない。
- **ソース確認**: GPL 公開ツリー（3.10.33）の該当行を読んで確定したもの。
- **推定**: 上の 2 つで決まらないもの。必ず「推定」と書いてある。

そして **撤回** を独立した章（第 15 章）にまとめてある。
一度主張したが実測で否定した 45 件を、すべて残した。
同じカーネルを触る人が同じ罠を踏まないためには、成功の記録より失敗の記録の方が役に立つ。
